# Claude's Cookbook

A family cookbook website built with HTML, CSS, and JavaScript to organize and share family recipes.

Visit the live site: [www.claudescookbook.com](https://www.claudescookbook.com)

## Features

- Browse family recipes and view ingredients and instructions
- Browse recipes through a dedicated recipe index
- Adjust serving sizes and scale ingredient quantities, and convert between weight units (lb / kg / oz)
- Save and access favorite recipes
- Import recipes from public URLs using a Cloudflare Worker
- Extract recipe titles, images, serving yields, ingredients, and directions from supported recipe websites

## Technologies

- HTML
- CSS
- JavaScript
- jQuery
- Cloudflare Workers
